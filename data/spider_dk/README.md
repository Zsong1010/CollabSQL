# spider_dk

Spider-DK eval pack for CollabSQL.

- `databases/` — full SQLite DBs (10)
- `fragments/horizontal_n4/` — 4-agent horizontal shards + `plan.json`
- `spider_dk.parquet` — 532 eval queries
- `cache/step80_spider_dk_@16_result.parquet` — EFPL trajectory cache
